## Codebase Patterns
- **Pattern:** When testing mutable exported arrays (like `ZERO_COST_MODELS`), save state in `const original = [...ARRAY]`, clear in `beforeEach`, and restore in `afterAll`.
- **Pattern:** `packages/core/test/providers` contains tests for providers logic, while `packages/core/src/util/__tests__` contains tests for util logic.
- **Pattern:** When adding new fields to `UnifiedRequest`, ensure they are correctly mapped in ALL provider request transformers (`packages/core/src/providers/*/request.ts`) AND format transformers (`packages/core/src/formats/*/request.ts`).
- **Pattern:** Use `createLogger({ service: '...', module: '...' })` for structured logging.
- **Pattern:** For Antigravity auth, always iterate through `ANTIGRAVITY_ENDPOINT_FALLBACKS` and handle failures gracefully.
- **Gotcha:** `biome` linting is strict about `any`. Use `// biome-ignore lint/suspicious/noExplicitAny: <reason>` when you genuinely need flexible types for protocol bridging or Discriminated Union workarounds.
- **Pattern:** Thinking blocks should be stripped from conversation history in multi-turn scenarios (reference: opencode-antigravity-auth "Strip ALL thinking blocks" strategy).
- **Pattern:** thoughtSignature must be stripped before logging for security.
- **Pattern:** Model capability configs in `model-capabilities.ts` use regex patterns checked in order (first match wins). More specific patterns must come before general ones.
- **Pattern:** OpenAI Chat format `reasoning_effort` only supports `none|low|medium|high`; filter `minimal|xhigh` when mapping from `ReasoningEffort`.
- **Pattern:** Unit tests for `packages/core/src/providers/*` are located in `packages/core/test/providers/`, not colocated.
- **Pattern:** `BackoffStrategy` logic should be kept separate from retry loop logic to allow for independent testing and reuse.
- **Pattern:** Parsing `Retry-After` headers requires handling both seconds (number) and HTTP Date strings.
