## Codebase Patterns
- Thinking logic in `transform-pipeline.ts` uses `isThinkingEnabled === false` (explicit disable) rather than `!== true`
- Default fallbacks for thinking (budget: 1024, includeThoughts: true) are in `@llmux/core/src/transform/thinking.ts`
- Use `camelToSnakeKey` and `snakeToCamelKey` from `@llmux/core/src/utils/casing.ts` for key conversion
- Use `convertKeysDeep()` from `@llmux/core` for recursive key transformation at provider boundaries
- When using `convertKeysDeep` for Gemini/Antigravity, use `preserveTree: ['parameters', 'args', 'response']` to protect user-defined keys
- ThinkingMode type is in `types/provider-strategies.ts` - reuse it for mode definitions
- ThinkingPolicy interface is in `@llmux/core/src/thinking/thinking-policy.ts` - central source of truth for thinking decisions
- Use `isThinkingModel()` from `@llmux/core/src/thinking/model-capabilities.ts` for table-driven model capability detection
- Use `computeThinkingPolicy()` from `@llmux/core/src/thinking/thinking-policy.ts` to compute thinking policy from request inputs
- `ThinkingPolicy` is the central source of truth for thinking/reasoning behavior (enabled, mode, includes)
